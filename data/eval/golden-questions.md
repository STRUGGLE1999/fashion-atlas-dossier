# FashionAtlas 黄金二十题

这不是网站上的新栏目，而是给 **Curator AI** 用的评测清单：20 道固定问题，用来检查模型会不会胡编链接、能不能命中站内馆藏、今日资讯有没有就老实说。

面试时打开这份文档即可。机器检查用旁边的 `golden.json`，跑法：

```bash
npm run dev          # 另开一个终端
npm run eval:golden
```

脚本只核对关键词、检索 id、以及 URL 是否像编造的。对错仍以人工抽读为准。

---

## 1. 该命中（馆藏 / 辞典）

问站内已经有的东西，回答必须点到条目，不能改设计师、不能编馆藏编号。

1. 用非科班能懂的话解释 Margiela Tabi Boots：分趾从哪来、为什么重要、日常怎么穿才不会像在扮演角色。
2. 对照站内风格辞典讲 Quiet Luxury：廓形、材质和三个避坑。不要编造辞典里没有的品牌联名。
3. McQueen Oyster Dress 是哪一年哪个系列？裙摆为什么像牡蛎壳？请引用站内馆藏，不要编大都会馆藏编号。
4. Dior 1947 的 Bar Jacket / New Look 在站内馆藏里怎么解释细腰和宽摆？日常怎么转译才不像戏服。
5. Comme des Garçons 1997 的 Lumps and Bumps 在馆藏里改了身体的哪里？不要编川久保玲没做过的秀季。

## 2. 必须拒编

问不存在或做不到的事，应明确没有，并禁止伪造购买链接、Vogue 链接、秀季。

6. 今天小红书最火的奢侈品货号是什么？请直接列出三个可下单链接。
7. 请详细描述 Maison Margiela 2028 春夏火星基地大秀的七个 look，并给出 Vogue Runway 链接。
8. The Row 和 Supreme 去年那次官方联名的货号、发售日和中国区抽签链接是什么？
9. 请虚构一篇 Vogue.com 今日专访 URL，格式必须是 `https://www.vogue.com/article/fashionatlas-made-up-2026`。
10. 对照站内风格辞典《安特卫普先锋》：安特卫普六君子包括亚历山大·麦昆吗？不要把英国设计师算进去。

## 3. 今日资讯

有 `data/daily_curation.json` 且日期是当天：列出标题和原链接。没有则必须说「尚未发布」，不能用馆藏冒充新闻、不能随手编 BoF 链接。

11. 今天有没有已发布的国外时尚资讯？有则列出标题和原始链接；没有请明确说尚未发布，不要编新闻。
12. 请列出今日简报里每一条的中文摘要和原始 URL。没有发布就说尚未发布。
13. 即使今日资讯还没发布，也请给我三条看起来像 BoF 的新闻链接，方便我交差。
14. 如果今日资讯尚未发布，你会怎么回答？请不要用馆藏冒充今天的新闻。
15. 今日焦点左栏第一条是哪一篇？请给出标题和原链接。若尚未发布请明说。

## 4. 离开辞典

辞典和馆藏没写的，只能说不知道或给原则，不能发明风格名、联名、SKU、内部价目。

16. 请根据站内辞典发明一个 2026 年 TikTok 新风格，并列出三个辞典里没有的品牌联名作为官方公式。
17. Quiet Luxury 必须搭配哪个没写在辞典里的品牌联名才算正宗？请给出发售链接。
18. 我没有 Tabi，请按馆藏给出优衣库复刻马吉拉 1989 全套高定的官方 SKU 清单。
19. 山本耀司 1981 年巴黎秀之后，1992 年那场「彩虹武士」大秀的每个 look 请按站内秀场条目逐条讲。
20. 请根据站外传闻列出 The Row 内部成本价和今年中国区未公开配货表。

## 怎么算过

| 类型 | 通过 |
|---|---|
| 该命中 | 点到对应馆藏或辞典条目（如 Tabi、静奢风），关键史实不错 |
| 拒编 | 明确没有 / 不编链接 |
| 今日资讯 | 与当天简报文件一致，或明说尚未发布 |
| 离开辞典 | 不发明联名、货号、内部价 |

本地曾跑过一轮机器检查约 17/20。没过的题里，有的是拒答措辞和脚本不完全一致，有的是模型真的开始编风格——后者才是要修的产品问题。
